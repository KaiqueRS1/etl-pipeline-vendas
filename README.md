# ETL Pipeline de Vendas

Mini pipeline de Engenharia de Dados desenvolvido com Python e Pandas.

## Fluxo

Raw → Extract → Transform → Validate → Load

## Funcionalidades

- leitura de arquivos CSV
- limpeza e padronização
- conversão de tipos
- tratamento de duplicatas
- separação de registros inválidos
- validação de qualidade
- integração entre clientes e pedidos
- exportação para CSV e Parquet
- logging
- testes automatizados

## Tecnologias

- Python
- Pandas
- PyArrow
- Pytest
- Git

## Executar

```bash
python -m src.pipeline
